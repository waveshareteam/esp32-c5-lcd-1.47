# Support

For setup and product usage, start with the
[ESP32-C5-LCD-1.47 documentation](https://docs.waveshare.com/ESP32-C5-LCD-1.47/),
the [hardware reference](HARDWARE_REFERENCE.md), and the README inside the
selected example.

For a reproducible repository defect, open an issue and include:

- board and hardware revision, if known;
- example path and framework version;
- complete build, flash, and serial logs;
- reproduction steps, expected behavior, and actual behavior;
- whether the image came from source CI or `firmware/`;
- changes to pins, BSP dependencies, board options, or storage layout.

For order, warranty, or product support, use the channel listed on the product
page and include the order number. Do not report security vulnerabilities in a
public issue; follow [SECURITY.md](SECURITY.md).
