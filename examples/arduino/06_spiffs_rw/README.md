# SPIFFS RW

This sketch mounts SPIFFS and runs a small file read/write check in flash.

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32c5 examples/arduino/06_spiffs_rw
```

Select a partition scheme that includes SPIFFS before flashing.
