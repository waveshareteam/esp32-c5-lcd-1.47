# Wi-Fi Scan

This sketch scans nearby Wi-Fi APs and prints the strongest results to the serial monitor.

```bash
arduino-cli compile --fqbn esp32:esp32:esp32c5:PartitionScheme=huge_app --libraries libraries \
  examples/arduino/07_wifi_scan
```
