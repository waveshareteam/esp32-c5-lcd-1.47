# Backlight Fade

This sketch fades the LCD backlight with Arduino LEDC APIs and shows the current brightness with LVGL `9.5.0`.

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32c5 examples/arduino/03_backlight_fade
```
