# LVGL Hello

This sketch starts LVGL `9.5.0` and draws a compact dashboard on the LCD using `GFX_Library_for_Arduino` as the display driver.

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32c5 examples/arduino/02_lvgl_hello
```
