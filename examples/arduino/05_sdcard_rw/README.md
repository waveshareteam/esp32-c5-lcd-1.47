# SD Card RW

This sketch displays an LVGL status page on the LCD, mounts the microSD card over SDSPI, and runs a small file read/write check.

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32c5 examples/arduino/05_sdcard_rw
```
