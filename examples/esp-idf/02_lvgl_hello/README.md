# LVGL Hello

This example starts the BSP LVGL port and draws a compact dashboard on the LCD.

```bash
idf.py -C examples/esp-idf/02_lvgl_hello set-target esp32c5
idf.py -C examples/esp-idf/02_lvgl_hello build flash monitor
```
