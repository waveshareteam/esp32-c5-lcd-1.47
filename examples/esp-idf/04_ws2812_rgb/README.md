# WS2812 RGB

This example cycles the onboard WS2812B LED through several colors.

```bash
idf.py -C examples/esp-idf/04_ws2812_rgb set-target esp32c5
idf.py -C examples/esp-idf/04_ws2812_rgb build flash monitor
```
