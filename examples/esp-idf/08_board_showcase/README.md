# Board Showcase

This integrated demo shows board status on the LCD while checking the onboard WS2812B LED, SPIFFS, optional microSD card, and Wi-Fi scan.

```bash
idf.py -C examples/esp-idf/08_board_showcase set-target esp32c5
idf.py -C examples/esp-idf/08_board_showcase build flash monitor
```
